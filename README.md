# Customers Dataset Preprocessing Project

## 📋 Project Overview
A comprehensive data preprocessing system for cleaning and preparing Customers Dataset for AI/ML applications and CRM systems.

## 🎯 Features
1. **Data Loading** - Load CSV dataset with 12 customer fields
2. **Data Exploration** - Analyze customer demographics, geography, subscription patterns
3. **Quality Analysis** - Detect missing values, duplicates, contact information issues
4. **Data Cleaning** - Automated cleaning pipeline for customer data
5. **Data Enrichment** - Create derived columns for better analysis
6. **Data Export** - Save cleaned data for CRM or analytics

## 📊 Dataset Fields (12 columns)
- Index
- Customer Id
- First Name
- Last Name
- Company
- City
- Country
- Phone 1
- Phone 2
- Email
- Subscription Date
- Website
